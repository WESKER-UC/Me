# James JG — Personal `.me` site

A minimal personal portfolio built with plain HTML, CSS and JavaScript.

## Before publishing

1. Replace `YOUR_EMAIL@example.com` in `index.html`.
2. Replace the LinkedIn placeholder with your real profile URL.
3. Add/remove projects as your portfolio changes.
4. Push the three files to the GitHub Pages repository for your `.me` domain.

## Files

- `index.html` — page structure/content
- `style.css` — design/responsive layout
- `script.js` — theme toggle, scroll reveals, smooth navigation

No framework or build step is required.
